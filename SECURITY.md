# Security Policy

## Supported Versions

Security fixes are provided on a best-effort basis for the current maintained branch and the latest released version.

Older unmaintained versions may not receive security updates.

## Reporting a Vulnerability

Please do not open a public issue for a suspected security vulnerability.

If GitHub private vulnerability reporting is enabled for this repository, use that channel.

If private reporting is not available, contact the repository maintainer privately through the repository owner contact listed on GitHub before public disclosure.

Include:

- a description of the issue
- steps to reproduce it
- the potential impact
- any suggested fix or mitigation, if available

## Disclosure Guidance

- Please allow reasonable time for triage and a fix before public disclosure.
- We will coordinate on disclosure timing once the issue is understood.
- If you would like credit in a security note or release note, mention that in your report.
